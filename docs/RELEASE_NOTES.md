# AI Bro 0.9.5 开发预览版

从 [本版 Release](https://github.com/zihenghe04/AIBro/releases/tag/v0.9.5) 下载 Mac Apple Silicon 安装包。需要 macOS 14+，采用未公证的 ad-hoc 签名。

本版重点改进对话交互与执行过程：发送、流式回答和思考段有了连贯的过渡；执行过程改为时间线；PDF 和文档中划词即可解释、翻译、批注或问 AI；模型请求瞬时失败会自动重试，未收到结果的工具会标记为「结果未知」而不是自动重放。

本版不包含新的移动端安装包，Android 0.4.9 APK 仍在 [v0.9.4 Release](https://github.com/zihenghe04/AIBro/releases/tag/v0.9.4) 提供。详见 [更新日志](../CHANGELOG.md) 和 [安装说明](DISTRIBUTION.md)。
